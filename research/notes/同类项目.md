## 1. BandOTP（lin945/mi_band_mfa）——本项目的主要参考

### 1.1 手环端
- manifest：`package=asia.bilibili.mfa`、`minPlatformVersion=1000`、`deviceTypeList:["watch"]`、`features: system.router/system.storage/system.interconnect`、`config.designWidth="device-width"`。**[已验证]**
- 协议：单条消息 `mfa_config_snapshot`（**全量快照一个 JSON**），手机→手环；手环→手机回 `mfa_config_response`（含 snapshot）。**没有分片/大小处理**。
- 手环端接收实现（`src/pages/index/index.ux`）：
  ```js
  import interconnect from "@system.interconnect"
  phoneConnection = interconnect.instance()
  phoneConnection.onmessage = message => {
    const payload = this.extractPayload(message)   // string 或 message.data
    const snapshot = parseConfigSnapshot(payload)  // JSON.parse + 结构校验
    saveMfaAccounts(snapshot.configs, ...)
  }
  phoneConnection.send({ data: response, success: () => {}, fail: () => {} })
  ```
  **[已验证]**
- 本地存储：`@system.storage` 单 key `mfa_config_snapshot`，整体 get/set（无 staging/原子写）。**[已验证]**
- TOTP：纯 JS 实现 HMAC-SHA1（`src/common/scripts/totp.js`），支持 6/8 位、15–120s（README 表述），**只支持 SHA-1**。**[已验证]**
- UI：一屏 1 或 2 个验证码（`layoutMode`），分类左右切换、分页、详情页、菜单页、版权页；480 宽基准布局（designWidth=device-width）。**[已验证]**
- 安装/发行：README 提供 AstroBox 直链（资源 id `asia.bilibili.mfa`），并给出 GitHub Releases `.rpk`。README 只写"小米手表/手环"，**未逐机型列出 10 Pro**（"9/9 Pro/10/10 Pro 可用"来自本项目 README，属二手结论）。**[已验证-README / 机型未逐项验证]**

### 1.2 手机端（mfa_android）
- `applicationId=asia.bilibili.mfa`（与手环端**同名**）；`minSdk 28`、`compileSdk/targetSdk 36`；`implementation(files("libs/xms-wearable-lib_1.4_release.aar"))`。**[已验证]**
- 流程：`NodeApi.connectedNodes` → `AuthApi.checkPermissions(node.id, [DEVICE_MANAGER])` → 未授权则 `requestPermission` → `MessageApi.sendMessage(node.id, payload)`；`ServiceApi.registerServiceConnectionListener` 更新 UI。**没有 addListener（所以收不到手环 ack）**。**[已验证]**
- 消息编码：`WearableConfigSnapshotCodec.encodeSnapshot(configs, reason)` → 单条 JSON（UTF-8 byte[]）。账号少时没问题；账号多时可能触及未知上限。**[已验证-源码；上限未验证]**
- 发现的问题：README 说明未配置 release 签名（本项目需要补）；不支持 SHA256/512、6–8 位、15–120s 限制比 Stratum 窄。**[已验证]**

## 2. BandTOTP（leset0ng）——更活跃的社区实现

### 2.1 手环端
`manifest.json`（`master`）：**[已验证]**
```json
{
  "package": "com.lst.bandtotp", "name": "BandTOTP", "versionName": "1.1", "versionCode": 2,
  "minPlatformVersion": 1000, "deviceTypeList": ["watch"],
  "features": [{ "name": "system.interconnect" }, { "name": "system.storage" }, { "name": "system.prompt" }],
  "config": { "logLevel": "log", "designWidth": 192 }
}
```
- **designWidth=192**：面向胶囊屏手环 9/10（192×490 基准）；10 Pro 资源复用了同一构建（见 2.3），说明同一 rpk 可跨 9 Pro/10 Pro 安装（是否排版最佳未验证）。
- 单页 `pages/index/index.ux` + `pages/index/totp.js`，无 router 多页；UI 用绝对定位 + `progress` 圆弧；字体 20–40px（designWidth 192 基准）。
- 通信：`interconnect.instance()`、`conn.onmessage = (data) => { JSON.parse(data.data).list }`；手机端发送 **单个 JSON 对象** `{"list":[...]}`，**无分片**。**[已验证]**
- 存储：`@system.storage` 保存列表 + 主题/分类等；支持删除（双击确认）、详情弹层。**[已验证]**
- TOTP 支持 SHA1（与 BandOTP 类似）；社区版后续加了 Steam。**[已验证-二手]**

### 2.2 手机端
- `applicationId=com.lst.bandtotp`、`minSdk 27`、`compileSdk 34`、`implementation files('libs/xms-wearable-lib_1.4_release.aar')`。**[已验证]**
- **签名**：`signingConfigs.release` 指向作者自己的 `lst.jks`（密码硬编码在仓库里，反面教材），且 **debug 与 release 共用同一个签名配置** → 安装包与手环 rpk 用同一证书，保证 interconnect。**[已验证]**
- 流程：`checkAndRequestPermissions()`（先 BLUETOOTH 运行时权限）→ `NodeApi.connectedNodes` → `AuthApi.checkPermission(nodeId, DEVICE_MANAGER)` → 未授权 `requestPermission` → `sendMessage(nodeId, "{\"list\":$datas}".toByteArray())`。**[已验证]**
- 无 `addListener`，不处理 ack。**[已验证]**
- 导入：读取 Stratum **URI 列表文本**（不是加密备份），解析 otpauth 行后发送。**[已验证-README + bandbbs 指南]**

### 2.3 AstroBox 资源与安装结构
`astrobox-res-bandtotp/manifest_v2.json`：**[已验证]**
- `restype: "quick_app"`，`item.id: "com.lst.bandtotp"`，含 `preview/media/icon/author`。
- `downloads` 是 **device key → 文件** 映射：
  `xmb9`（手环9）、`xmb9p`（9 Pro）、`xmb10`（手环10）、`xmb10p`（**手环10 Pro**）、`xmrw5/xmrw5xring/xmrw6`。
- 关键观察：`xmb9p` 与 `xmb10p` 使用**同一个文件**（`com.lst.bandtotp.release.1.1.1.rpk`）→ 同一 rpk 可同时装 9 Pro 与 10 Pro；`xmb10`/`xmb9` 用另一 `1.1 10.rpk`/`1.1 9.rpk`（按屏幕形状出不同包）。
- 资源说明写"可搭配 astrobox 同步器插件使用"→ 插件生态是社区惯用做法（本项目不需要）。

### 2.4 社区反馈（可直接进 FAQ）
- **"fingerprint verify failed ... 一直提示手环方面未安装"**：两端证书/包名不一致的典型现象；重装/重签后出现。**[已验证-二手]**
- 导入前需在 Stratum 里给每个账号填好 **账号名**，否则导出的 URI 缺少 username，部分解析器不识别。**[已验证-二手]**
- 有用户反馈：选择的文件在 Download 目录时显示成功但实际未导入（SAF/路径问题）；换到根目录成功 → 提醒：导入器要真正读流并校验，不要只看路径/结果码。**[已验证-二手]**
- 手环端开启震动后返回不震动等 UI 小问题。**[已验证-二手]**

## 3. 其它社区经验

### 3.1 签名/重打包
- 「快应用封装/改名」教程：过程会**破坏原始签名**，会导致含手机通信/签名校验的快应用失效，且**未签名 rpk 直装可能导致手环重启或快应用变临时文件**。→ 安装包必须由 `aiot release` 正常产出，不要手工 re-zip/重签。**[已验证-二手]**（<https://www.bandbbs.cn/threads/21364/>）
- 自编译 rpk 用 **IDE 默认 debug 签名**可在手环 10 NFC 上正常安装（不能通信是另一回事）。**[已验证-二手]**（<https://www.bandbbs.cn/threads/26051/>）→ 设备安装阶段接受自签；**interconnect 阶段**才要求与手机端一致。
- 10 Pro 专属应用发行说明："安装包共 2 个版本：普通版（体积小兼容性好）、JSC 优化版（性能好体积大）；**包名与签名和手环 9/10 版一致，同步器可正常连接**。"→ 佐证：跨版本保持包名+签名不变是同步器兼容前提。**[已验证-二手]**（<https://www.bandbbs.cn/resources/8252/updates>）

### 3.2 10 Pro / Vela 5 兼容
- 10 Pro 运行 Vela 5，**不支持 fetch**；"部分使用 protobuf+jsc 打包的快应用在 10 Pro 上不可用"；不要装标注支持 fetch 的 9 Pro 资源；先选对设备型号再安装。**[已验证-二手]**（<https://www.bandbbs.cn/threads/29315/>）
- 装完快应用要**重新连接小米运动健康**，否则快应用像没有权限/连不上设备。**[已验证-二手]**
- AstroBox 报 `third-party app install failed: InstallFailed 3` 时：等上一个应用加载完、清空间、确认机型。**[已验证-二手]**
- 10 Pro 无 20 个快应用数量上限（与 Watch S5 同）。**[已验证-二手]**

### 3.3 消息大小处理
- BandOTP/BandTOTP 都是**单条 JSON 全量发送**，没有分片；账号规模小（个位数~几十）时可用。**[已验证]**
- 官方 interconnect 图片传输样例采用 **header→data→end 三段分片**（每片 Base64），说明大消息必须自行分片；本项目协议 v2 的 begin/account×N/commit 正是同一思路。**[已验证-官方样例]**
- 我们的 `account` 单条 <1 KB，理论安全；仍需真机测上限。

### 3.4 构建
- 都是 `aiot build` / `aiot release`（aiot-toolkit 2.x），产物在 `dist/*.rpk`；`release` 需要 `sign/{private,certificate}.pem`（或 `sign/release/`）。**[已验证]**
- 社区也会用 IDE 默认 debug 证书出包给测试者（不可用于 interconnect 正式联调）。**[已验证-二手]**

## 4. 可复用结论（给本项目）

1. **签名**：一套自签证书（JKS+PEM），APK 的 debug/release 与 rpk 的 release 全部用它；不要依赖"统一签名"。
2. **包名**：两端必须完全一致（`dev.wristkey.app`），且手环快应用 manifest 的 `package` 就是它。
3. **消息**：小包分片正确；参考项目单包全量只是账号少的将就。ack 用 `MessageApi.addListener`（参考项目都没做，属增量能力）。
4. **UI**：10 Pro 按 480×336 设计；参考项目的大小（BandOTP device-width / BandTOTP 192 基准）可借鉴布局但不要照抄尺寸。
5. **安装**：AstroBox 选 `xmb10p` 装自签 release rpk；装完重连运动健康；不要用封装/重签工具。
6. **兼容**：10 Pro 用普通构建（非 protobuf/jsc）先验证；JSC 版本可作为后续优化。
7. **导入**：Stratum URI 列表是社区验证过的最简路径；但本项目要支持加密备份（更强）。
