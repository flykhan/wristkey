# 手环 UI v3 设计规格（已与用户确认）

截图参考：`docs/design/ui-v3-main-3perpage.jpg`、`ui-v3-letter-picker.jpg`。

## 主界面（pages/index）

- **无顶栏**：不显示"腕证/分类/同步状态/菜单"行；屏幕全部给验证码。
- **每页 3 个账号**（`ACCOUNTS_PER_PAGE = 3`），上下滚动/滑动翻页。
- 左侧列表宽 = 内容宽 - 右侧 rail(56px)；每行一个圆角卡片：
  - 第一行：issuer 大字（21px bold）+ 账号名小字（13px，同一行，省略号）
  - 第二行：验证码大字（6 位 42px；8 位 40px；10 位 34px；Steam 5 位 42px），右侧显示剩余秒数（14px）
  - 底部 3px 进度条
- 右侧 rail（56px，垂直排列）：
  - 顶部圆形按钮 44×44：默认显示 `A-Z`；有筛选时显示当前字母（如 `S`）并高亮
  - 按钮下方显示页码 `4/16`（按筛选后的列表计算）
- 手势：上滑下一页、下滑上一页；**右滑打开菜单**；左滑退出应用；点击卡片进详情。

## 首字母筛选页（pages/picker）

- 从右侧按钮进入；标题"首字母筛选"，右滑返回。
- 7 列网格，共 38 格：A–Z（26）+ 0–9（10）+ `全部` + `#`（其他：中文/符号）。
- 每格显示字母 + 该字母账号数（小字）；有账号的高亮，无账号的置灰不可点；当前筛选字母有描边。
- 点击字母：写入 `wristkey_letter_filter`（`A`…`Z`、`0`…`9`、`#`，空串=全部）→ `router.back()`；点"全部"写入空串。
- 计数按"全部账号"统计（忽略分类）。

## 筛选规则

- 账号的字母桶：优先 issuer 的首字符，issuer 为空时用账号名；转大写后：
  - A–Z / 0–9 → 对应桶
  - 其他（中文、符号、空）→ `#`
- 筛选在**全部账号**内进行（忽略分类），筛选后仍 3 个/页。
- 筛选持久化在 storage，重进应用保留；"全部"清除。

## 其它

- 菜单页移除"分类"入口（分类不再影响主列表；分类仍保存在账号数据里供详情展示）。
- 同步状态/请求同步入口保留在菜单页（右滑进入）。
- 版本：rpk **1.0.4 / versionCode 5**。
