# 使用指南（真机流程）

> 本文面向最终用户；工程/构建细节见 [build-install.md](build-install.md)。当前版本 v2.0（手环 2.0.0 / 手机 2.0.0）。

## 0. 前置条件

- 小米手环 10 Pro 与手机已在「小米运动健康」中正常配对（HyperOS 3 固件）；
- 手机 Android 9+；
- 手环端已安装本项目的 `.rpk`，手机端已安装**同包名、同签名**的 APK（否则手环与手机无法建立通道）；
- 首次升级 v2.0 请**两端一起升级**；只升级一端时，旧手环会忽略 v3 消息，手机端 8 秒后提示"未收到手环确认"。

## 1. 从 Stratum 导出备份

在 Stratum 中：**设置 → 备份 → 导出**，三种可用形式（任选其一）：

| 方式 | 操作 | 文件 |
| --- | --- | --- |
| 加密备份（推荐） | 设置密码后导出 | `backup-YYYY-MM-DD_HHmmss.stratum` |
| 明文备份 | 密码留空直接导出 | `backup-YYYY-MM-DD_HHmmss.stratum` |
| URI 列表 | 导出 URI list | `backup-YYYY-MM-DD_HHmmss.txt`（每行 `otpauth://`） |

> 不要用 **HTML** 导出：它含二维码和明文 secret，且**不能导回**，App 会识别并提示。
> 导出后请尽快导入，并删除手机/电脑上的备份文件（加密备份也建议删除）。

## 1b. 从 Bitwarden 导出（可选，v2.0 支持密码）

也支持 Bitwarden 保险库 JSON（**未加密**）：

1. Bitwarden → **设置 → 导出保险库 → .json**；
2. 导出时**不要**选择"密码保护/加密"（加密导出暂不支持，App 会提示）；
3. 文件里有全部密码，不只是 TOTP，导入后请立即删除。

> 读取每个条目的 `login.totp`、用户名与密码；文件夹/分类不导入（统一归"默认分类"）。
> Stratum 备份不含密码，因此 Stratum 导入不会覆盖手环上已有的密码；Bitwarden 空密码会清空。
> 详细字段映射见 [bitwarden-format.md](bitwarden-format.md)。

## 2. 把文件放到手机

- 通过微信/QQ/网盘/数据线把备份文件保存到手机；
- 无需特定目录：导入时用系统文件选择器选择即可；
- 也可在文件管理器中"用其他应用打开"→ 选择「腕证」。

## 3. 在 App 中导入（v2.0 新界面）

1. 打开「腕证」，底部三个 Tab：**账号 / 同步 / 设置**；
2. 在「账号」页点右下角 **＋**，选择"导入备份"（支持 Stratum 与 Bitwarden，按内容自动识别）；
3. 选择文件：
   - Stratum 加密备份 → 输入导出密码（只在内存中使用，不保存）；
   - Stratum 明文 / URI 列表 / Bitwarden JSON → 直接解析；
4. 弹出导入预览：**导入 N / 更新 M / 跳过 K**，跳过项列出原因（HOTP、Yandex、Mobile-OTP、非法 Base32、
   周期/位数越界等）；Steam 显示 5 位字母数字码（如 `3DP36`）；
5. 选择「合并」（按 secret 去重，已有更新，未出现保留）或「全量替换」；
6. 点账号卡可看详情：大号验证码、倒计时、用户名、密码（默认遮罩，点按显示 10 秒）；
   右上角可编辑/删除，编辑页可改 issuer、账号名、密码、算法、位数、周期。

## 4. 同步到手环

1. 底部「同步」页确认连接状态；首次使用点 **申请设备管理权限** 并在系统弹窗允许；
2. 点 **同步到手环**（导入/修改后会自动尝试一次）；
3. 页面显示进度与结果；收到手环确认会显示"手环已确认"，8 秒无确认会提示旧版或连接问题。
   没有确认也不影响手环离线使用，下次手环请求同步时会重发；
4. 手环端也可在菜单页点「立即同步」反向请求手机推送。

## 5. 入口图案（v2.0 新增，双端可设）

- **在手机上设置**：设置 → 入口图案 → 依次点 5 个图形（可重复）→ 再点一遍确认 →
  自动通过 `mfa_pin_set` 下发到手环；关闭图案同样在手机上操作（手机是信任根，不需要手环旧图案）；
- **在手环上设置**：菜单 → 入口密码 → 先验证旧图案（首次无旧图案则跳过）→ 输入两次新图案；
  手环端修改/关闭也必须验证旧图案；
- 锁屏规则：手环冷启动、或在其它页面停留超过约 2 分钟后回到应用，需要重新输入；
- 连续输错 5 次锁定 30 秒，此后继续错会递增；忘记图案时在手机端重设并重新同步即可；
- 图形颜色固定：三角薄荷绿、方形雾蓝、圆形暖橙（不受表盘主题影响，便于记忆）。

## 6. 在手环上查看（v2.0 新界面）

- 打开「腕证」先见图案锁屏：5 个圆点 + 三个图形按钮，按顺序点满 5 位自动校验；
- 主界面每页 **3 个账号**：issuer + 账号名小字 + 大号验证码 + 剩余秒 + 进度条；
- 上下滑动翻页；右侧竖条：顶部圆形 **A-Z** 按钮（当前筛选字母/全部）、筛选后账号数、页码、底部「菜单」；
- 点 **A-Z** 打开全屏 4×4 网格（上下滑动共 3 页：A–P、Q–Z+0–5、6–9+#+全部），
  每个键显示该字母账号数，无账号置灰；选字母后在全部账号中筛选，选「全部」清除；
- 点账号卡进入详情：用户名、密码（遮罩，点按显示 10 秒）、验证码；左滑返回/退出；
- 菜单：入口密码、立即同步、关于、退出。

## 7. 更新与删除

- 在 Stratum/Bitwarden 中增删账号 → 重新导出 → 在 App 中重新导入（合并/替换）→ 同步；
- 只想在手机端管理：App 内可手动新增/编辑/删除账号，改动后自动同步；
- 清空全部：App 内清空所有账号并同步（手环快照被空快照替换）；
- 修改入口图案：手机设置页直接改；手环菜单里改需旧图案。

## 8. 故障排查

| 现象 | 排查 |
| --- | --- |
| 导入提示密码错误 | 确认导出时密码；文件是否被截断；尝试重新导出 |
| 导入识别失败 | 确认是 `.stratum`/URI `.txt`，不是 HTML；文件是否完整 |
| 找不到手环/同步失败 | 确认手环与手机已配对且蓝牙开启；重新打开 App；检查"设备管理"权限 |
| 手环收不到同步 | 两端包名/签名是否一致（重新安装配套版本）；手环端在应用列表打开一次；确认两端都已升到 v2.0 |
| 手机提示"未收到手环确认" | 通常是对端仍是 1.x；两端一起升级后重新同步 |
| 手环验证码与手机不一致 | 检查手环系统时间；确认 issuer/位数/周期/算法导入正确 |
| Steam 账号显示 6 位数字（应为 5 位字母数字） | 旧版把 Steam 当普通 TOTP：两端升级到 v2.0，重新导入并同步 |
| Steam 账号未出现在手环 | 确认两端都已升级；旧手环会丢弃 Steam（digits=5）账号 |
| 手环一直要求图案/忘记图案 | 在手机 App「设置 → 入口图案」重设或关闭，再同步；手环端需旧图案才能本地改 |
| 手环提示"图案错误"后锁定 | 等锁定倒计时结束；连续错误会递增；也可在手机端重设后同步覆盖 |
| 手环端显示"未同步" | 手机端点同步；或手环菜单点「立即同步」请求推送 |
