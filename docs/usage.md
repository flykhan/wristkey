# 使用指南（真机流程）

> 本文面向最终用户；工程/构建细节见 [build-install.md](build-install.md)。

## 0. 前置条件

- 小米手环 10 Pro 与手机已在「小米运动健康」中正常配对（HyperOS 3 固件）；
- 手机 Android 9+；
- 手环端已安装本项目的 `.rpk`，手机端已安装**同包名、同签名**的 APK（否则手环与手机无法建立通道）。

## 1. 从 Stratum 导出备份

在 Stratum 中：**设置 → 备份 → 导出**，三种可用形式（任选其一）：

| 方式 | 操作 | 文件 |
| --- | --- | --- |
| 加密备份（推荐） | 设置密码后导出 | `backup-YYYY-MM-DD_HHmmss.stratum` |
| 明文备份 | 密码留空直接导出 | `backup-YYYY-MM-DD_HHmmss.stratum` |
| URI 列表 | 导出 URI list | `backup-YYYY-MM-DD_HHmmss.txt`（每行 `otpauth://`） |

> 不要用 **HTML** 导出：它含二维码和明文 secret，且**不能导回**，App 会识别并提示。
> 导出后请尽快导入，并删除手机/电脑上的备份文件（加密备份也建议删除）。

## 2. 把文件放到手机

- 通过微信/QQ/网盘/数据线把备份文件保存到手机；
- 无需特定目录：导入时用系统文件选择器选择即可；
- 也可在文件管理器中"用其他应用打开"→ 选择「腕证」。

## 3. 在 App 中导入

1. 打开「腕证」，点 **从 Stratum 导入**；
2. 选择备份文件：
   - 若是加密备份 → 输入导出时设置的密码（只在内存中使用，不保存）；
   - 若是明文备份 / URI 列表 → 直接解析；
3. 查看导入结果：**导入 N 个账号 / 更新 M 个 / 跳过 K 个**，跳过项会列出原因
   （HOTP、Yandex、Mobile-OTP、非法 Base32、周期/位数越界等）；**Steam 账号现在会正确导入**，
   手环显示 5 位字母数字码（如 `3DP36`），不是 6 位数字；
4. 选择导入方式：
   - **合并**（推荐）：按 secret 去重，已有的更新，未在备份中的账号保留；
   - **全量替换**：手机端账号以本次备份为准。

## 4. 同步到手环

1. 首页确认"已连接手环"；首次使用点 **申请设备管理权限** 并在系统弹窗中允许；
2. 点 **同步到手环**（导入完成后会自动尝试一次）；
3. 状态变为"已同步 N 个账号"（若收到手环 ack 则显示"手环已确认"；没有 ack 也不影响离线使用，
   下次手环请求同步时会自动重发）。

## 5. 在手环上查看

- 手环应用列表打开「腕证」；
- 左右切换分类，上下/分页切换账号，点开查看大号验证码与剩余时间；
- 同步完成后即使手机不在身边，手环仍可离线生成验证码（时间来自手环系统时间，需与手机保持同步）。

## 6. 更新与删除

- 在 Stratum 中增删账号 → 重新导出 → 在 App 中重新导入（合并/替换）→ 同步；
- 只想在手机端管理：App 内可手动新增/编辑/删除账号，改动后自动同步；
- 清空全部：App 内"清空所有账号"并同步（手环端快照被空快照替换）。

## 7. 故障排查

| 现象 | 排查 |
| --- | --- |
| 导入提示密码错误 | 确认导出时密码；文件是否被截断；尝试重新导出 |
| 导入识别失败 | 确认是 `.stratum`/URI `.txt`，不是 HTML；文件是否完整 |
| 找不到手环/同步失败 | 确认手环与手机已配对且蓝牙开启；重新打开 App；检查"设备管理"权限 |
| 手环收不到同步 | 两端包名/签名是否一致（重新安装配套版本）；手环端在应用列表打开一次 |
| 手环验证码与手机不一致 | 检查手环系统时间；确认 issuer/位数/周期/算法导入正确 |
| Steam 账号显示 6 位数字（应为 5 位字母数字） | 旧版把 Steam 当普通 TOTP：请同时升级手机 APK（≥1.1）与手环 rpk（≥1.0.2），重新导入并同步 |
| Steam 账号未出现在手环 | 确认两端都已升级；旧手环会丢弃 Steam（digits=5）账号 |
| 手环端显示"未同步" | 手机端点同步；或手环端点"请求手机同步"后再试 |
